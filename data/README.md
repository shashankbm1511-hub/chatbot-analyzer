# Sample data — synthetic

`sample_conversations.csv` contains **240 synthetic chatbot conversations** for a
fictional online retail / subscription service. It was generated by
[`scripts/generate_synthetic_data.py`](../scripts/generate_synthetic_data.py) from
hand-written templates with a fixed random seed (`--seed 42`).

- No real customers, companies, transcripts or personal data are included.
- `customer_id` values are random placeholders (`CUST-####`).
- Labels (`intent`, `resolved`, `escalated`) are set by the generator, so they are
  internally consistent but much cleaner than real support data.
- About 2% of `channel` and `response_time_seconds` values are intentionally blank
  to exercise the loader's missing-value handling.

Regenerate or resize it with:

```bash
python scripts/generate_synthetic_data.py --rows 300 --seed 7
```

## Data dictionary

| Column | Type | Description |
|---|---|---|
| `conversation_id` | string | Unique ID, e.g. `CONV-00012` (**required**) |
| `timestamp` | datetime | Conversation start time (Apr–Jun 2026) |
| `customer_id` | string | Pseudonymous customer ID; some customers appear more than once |
| `conversation_text` | string | Transcript, one message per line prefixed `Customer:`, `Bot:` or `Agent:` (**required**) |
| `intent` | string | One of 10 demo intents (Billing, Account/Login, Technical Issue, Order/Transaction, Refund, Cancellation, Product Information, Complaint, General Query, Other) |
| `channel` | string | `web`, `mobile_app` or `messaging` |
| `resolved` | bool | Whether the conversation ended with the issue resolved |
| `escalated` | bool | Whether it was escalated (live handoff or specialist ticket) |
| `response_time_seconds` | float | Average bot response time |
| `conversation_length` | int | Number of messages |

Conversation paths in the generator: resolved on the first answer, resolved after a
retry, abandoned unresolved (sometimes after asking for a human), escalated via a
ticket with no live agent, and escalated to a live human agent.
